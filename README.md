* HTML
* JavaScript

## Actividad 1: Sistema Básico de Inventario

El programa permite:

* Registrar productos.
* Registrar precios.
* Registrar existencias.
* Calcular el valor total del inventario.

## Actividad 2: Diagramas de Flujo

Diagramas realizados en Excalidraw:

* Sumatoria de números del 1 al 10.
* Números pares del 1 al 20.
* Números impares del 1 al 20.
* Números primos del 1 al 20.

Las imágenes se encuentran en la carpeta:

```text
IMAGENES
```
